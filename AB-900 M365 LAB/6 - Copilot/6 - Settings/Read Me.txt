/**Copilot**/

Copilot under Settings

Here we can see what needed to setup for the copilot functions according to policies
Mostly that needed to setup are the following
	
	1 - Data Security
		Prevent Leakage in Copilot Interactions - Turned On - Done
		Prevent SharePoint content from being overshared
		Enhance data compliance for Copilot interactions
		Turn on audit logs for your org
	2 - Workflow Enablement
		Enable connectors
		Allow agent access for users
		Allow access to agents built by your org
		Allow access to agents built by external providers
		Allow access to agents built by Microsoft
		Deploy agents to your organization
	3 - User Experiences
		Allows users to send feedback
		Pin Copilot apps to the Windows Taskbar
		Copilot meetings
		Allow Anthropic as Microsoft sub processor
		Pin Copilot in the Microsoft 365 apps
		Enable multimodal input and output for Copilot
